AmigaOS 3.2.3 · PrismRTG 1.4 beta 3

A clean A1200 from floppies to an RTG Workbench

Every step of a fresh install, recorded in WinUAE on 13 November 2026: partition an empty hard drive, install AmigaOS 3.2 from its floppies, update to 3.2.3, add the CPU libraries, then install PrismRTG from its release ADF. The screens are the real ones from the run; where the emulator needs something a real Amiga doesn't, the step says so. Networking is in the PrismNet repo's guide.

The machine

  • A1200, Kickstart 3.2.3 (47.115)
  • 68030 + 68882, 2 MB chip, 4 MB + 64 MB fast
  • UAE RTG card (UAEGFX), 16 MB, Zorro III
  • An empty 1 GB hard drive image

The disks

  • AmigaOS 3.2: Install, Workbench, DiskDoctor, Locale, Locale-EN, Extras, Classes, Fonts, Storage, Backdrops, GlowIcons, MMULibs
  • Update 3.2.3: Update3.2.3, Classes, DiskDoctor, Extras, Locale-EN
  • PrismRTG-1.4b3.adf (or the .lha) from the GitHub release
  1. Partition the drive
  2. Format the partitions
  3. Install AmigaOS 3.2
  4. Update to 3.2.3
  5. Add the CPU libraries
  6. Install PrismRTG
Changing floppies in WinUAE: press F12, open Floppy drives, click the … button next to DF0, choose the ADF and click OK. Then click Proceed in the installer. On a real Amiga you insert the disk it names.
1

Partition the drive

Boot from the Install3.2 floppy. Workbench opens with the Install3.2 disk; open it.

On a real A1200, open HDTools and double-click HDToolBox; it lists the IDE drive. In WinUAE the drive sits on WinUAE's own controller, so start HDToolBox from the Install disk's Shell and name that controller:

hdtools/hdtoolbox uaehf.device

Select the empty drive (status Unknown) and click Change Drive Type, then Define New…, then Read Configuration and Continue. HDToolBox fills in the drive's own geometry. Click Ok twice.

Pick the right unit in WinUAE. If a WinUAE host folder is attached (here Transfer), it shows up as another unit. Read Configuration on that one reports a drive the size of the PC's disk (953 GB here), and saving fails with Error 33 on write. The real drive reads as UAE a1200.hdf.

Click Partition Drive. The default setup makes two halves, the first one bootable. Rename them in Partition Device Name to DH0 and DH1 (click a partition in the bar to select it), keep International (FFS) and click Ok.

Click Save Changes to Drive. The status changes to Not Changed, which means it is written. Click Exit and reboot (in WinUAE: F12 → Reset). After the reboot the two partitions appear as DH0:Uninitialized and DH1:Uninitialized.

2

Format the partitions

The 3.2 installer only installs onto a formatted partition, so format both first. Either select the icon and use Icons → Format Disk…, or in the Install disk's Shell (Format is in SYS:System, not C:):

SYS:System/Format DRIVE DH0: NAME Workbench FFS INTL QUICK
SYS:System/Format DRIVE DH1: NAME Work FFS INTL QUICK

Press Return at each Press RETURN to begin formatting prompt.

3

Install AmigaOS 3.2

Close the Shell (EndCLI), open Install on the Install3.2 disk and double-click English. Click Proceed, keep Install Release 3.2, and choose Intermediate User so the installer asks before it decides.

Keep Install for Real. The installer finds the new Workbench: partition by itself; answer Yes. Then pick languages (English), printer drivers and keymaps (defaults are fine) and say Yes to GlowIcons, which look right on an RTG screen.

Insert each disk it asks for, in this order: Workbench, DiskDoctor, Locale, Locale-EN, Extras, Classes, Fonts, Storage, Backdrops, GlowIcons. It did not ask for a Modules disk, because the ROM is already 3.2.3.

Locale and Locale-EN are two disks. The installer first wants the disk named Locale and only then Locale-EN; inserting Locale-EN first gets Please insert correct disk.

Eject the floppy and reboot. The first boot stops at a message that the 68030's CPU library is missing; press Return. Workbench 3.2 comes up from the hard drive.

4

Update to 3.2.3

Insert Update3.2.3, open the disk, then Install → English. Choose Intermediate User, Install for Real, Yes to Workbench:, English, and Move when it offers to keep the old Startup-Sequence in Workbench:OLD.

It asks for the 3.2.3 disks Classes, DiskDoctor, Extras and Locale 3.2.3-EN. Remove the floppy and click Proceed; it reboots. The screen title now reads Workbench Release 3.2.3.

5

Add the CPU libraries

To stop the CPU-library warning at every boot, insert Install3.2 again, run Install → English and pick Install CPU Support Libraries. Answer Yes to MMULibs 46.21 in Workbench:, insert MMULibs, choose Other as the CPU card maker (an emulator, or a card not listed), and reboot without the floppy.

6

Install PrismRTG

Insert PrismRTG-1.4b3.adf. The PrismRTG disk holds PrismPrefs, PrismProbe, the guide, the ReadMe and Install_PrismRTG; double-click the installer. It starts in Intermediate User; click Proceed With Install, then Proceed.

The installer identifies the card on its own (here the UAE RTG card, which PrismRTG drives directly) and asks which screen Workbench should open on after the reboot. 800 × 600, 16-bit is the default.

Next comes a page of tips for a start that goes wrong: hold the left mouse button while booting to skip PrismRTG, then change the modes in Prefs/PrismPrefs; if Workbench comes back on a small Amiga screen, the bottom line of PrismPrefs says why. Click Proceed twice, eject the floppy and reboot. Workbench comes up on the RTG screen.

Recorded on WinUAE with an A1200 / KS 3.2.3 configuration, floppies swapped through the Floppy drives page. Differences from real hardware:

  • On a real A1200 HDToolBox finds the IDE drive when double-clicked; the uaehf.device command is only for WinUAE's controller.
  • Floppy speed was set to turbo, so the copy times are not representative of real drives.
